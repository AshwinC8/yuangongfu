What Google shows as your title and description in search results — previously placeholder text.

5 · Performance — Core Web Vitals

Done

Page speed is a Google ranking factor. The autoplaying videos were the main risk. No on-screen behaviour or design changed.

Videos load & play only when on screen

Before
Page renders in triplicate (infinite scroll) → all 3 copies of every clip downloaded AND autoplayed at once on load.
After
preload="none" + visibility gating → only the on-screen copy loads & plays; off-screen ones stay idle.

Why: Cuts initial data dramatically (≈⅔ of video weight removed at load) and stops wasted CPU/battery decoding hidden clips.

Poster frames on every video

A lightweight still image (~28 KB) paints instantly while the clip buffers — it becomes the Largest Contentful Paint element instead of a black box. Biggest win on mobile, where the hero clip is heavy.

Optimised footer logo

Moved to Next.js image optimisation → modern formats (AVIF/WebP), lazy-loaded, fixed dimensions to prevent layout shift (CLS).
